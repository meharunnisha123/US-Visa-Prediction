US Visa Prediction

This project is a US Visa Prediction System developed using Python to predict whether a visa application will be Approved or Denied based on applicant details and historical data.

The project includes data preprocessing, feature engineering, model building, and prediction to improve decision-making and understand factors affecting visa approval.

 Features

* Data cleaning and preprocessing
* Handling missing values
* Exploratory Data Analysis (EDA)
* Feature engineering
* Machine Learning model training
* Visa approval prediction

 Tools & Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Jupyter Notebook

Project Workflow

1. Load dataset
2. Clean and preprocess data
3. Perform EDA
4. Train machine learning model
5. Evaluate model performance
6. Predict visa approval status

Outcome

This project helps analyze visa application data and predict approval outcomes using machine learning techniques.
